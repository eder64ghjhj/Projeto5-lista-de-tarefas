# ✅ Lista de Tarefas

Aplicação de gerenciamento de tarefas (To-Do List) com funcionalidades de adicionar, concluir e excluir tarefas, desenvolvida com JavaScript puro.

## ✨ Funcionalidades

- Adicionar novas tarefas
- Marcar tarefas como concluídas
- Excluir tarefas
- Validação de campo vazio

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (ES6+)

## 📁 Estrutura do Projeto

```
│   └── styles.css

    └── script.js
```
